# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **rtl8188eu-hotspot-toolkit**, please report it responsibly by contacting Exequiel Echevarria via e-mail at [exemetal@hotmail.com](mailto:exemetal@hotmail.com).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or proof-of-concept
- System environment (Linux distribution, Kernel version, NetworkManager version)

All security reports will be acknowledged within 48 hours and resolved promptly.
